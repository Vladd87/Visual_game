# Device screenshots (current)

Screenshots from the target phone (Galaxy Z Fold8 Ultra, Adreno 840) of the
current look. The critic packet includes this folder for **milestone-end
judgements** (absolute scores of the build that ships), where the phone's
frames override the browser captures.

They are **left out of the paired round panels** (new vs best, X/Y blind):
they show only the newest build, so they would tell a critic which set is
new and tilt the comparison.

- `test15-cover-run-{a,b,c}.jpg`: test build 15, cover screen, mid-run
  (round-14 lighting candidate). First frames with the water drawn on the
  phone (see PLAN.md decisions: no `environment_lighting: false`).
